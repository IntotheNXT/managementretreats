# Management Offsites

Static bilingual website for **Management Offsites**.

Primary domain: https://www.managementoffsites.com

## Structure

- `index.html` – English landing page
- `nl/index.html` – Dutch landing page
- `explorer/index.html` – English guided offsite intake
- `nl/verkenner/index.html` – Dutch guided offsite intake
- `catalog-nl.json` / `catalog-en.json` – capability catalogue
- `data/` – facilitator, matching and proposal data
- `styles.css` – visual design and responsive layout
- `offsite-explorer.css` – guided intake and proposal design
- `facilitators.css` – facilitator profiles
- `script.js` – navigation, facilitator filtering and capability catalogue behaviour
- `offsite-explorer.js` – seven-question intake, matching and proposal generation
- `scripts/` / `tests/` – data validation and matching scenarios
- `sitemap.xml` / `robots.txt` – search-engine discovery

## Deployment

The site is deployed through Vercel from the `main` branch. Domain and DNS configuration are managed outside this repository.
