# ManagementRetreats

Static landing page for ManagementRetreats.nl / ManagementRetreats.co.uk.

## Structure

- `index.html` – Dutch landing page
- `styles.css` – visual design and responsive layout
- `script.js` – mobile navigation and current year

## Current CTA

All primary CTA buttons currently open an email to `info@intothenxt.com`. This can later be replaced by a dedicated intake form or another email address.

## Publishing with GitHub Pages

1. Open **Settings** in this repository.
2. Go to **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`.
5. Save.

GitHub will then publish the site on the repository's GitHub Pages URL.

## Custom domain

After the first version has been reviewed, connect `managementretreats.nl` as the primary Dutch domain. The `.co.uk` domain can later serve or redirect to an English version.
